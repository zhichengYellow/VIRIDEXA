## 真实浏览器结果

[可在浏览器打开的截图索引](../reports/ui-x/index.html) 汇总 33 张改造前、39 张改造后主要截图，覆盖 375 / 768 / 1440px；另有首页首屏和测试质量区域两张补充截图。所有主要最终几何检查无横向溢出。图鉴为新路由，无对应独立旧页面。助手初始态与实际结果分开保存。长页面最多保留前3200px；旧图谱基线含加载中的画面，未用其数据数量或时序声称性能收益。

已实走：

- 首页搜索银杏 → 图鉴结果 → 植物2详情 → plant:2图谱 → 科研实验台登录保护，真实 ID 保留。
- 图鉴列表切换、快速预览、快捷搜索提交及 Escape、手机导航展开/选路收起、新手指南真实对象准备。
- 图谱按需展开真实关系、侧栏、手机 Inspector、Escape 与 Shift+Tab 焦点边界；画布尺寸变化后重新适配。
- 使用既有隔离 ADMIN 技术账户完成登录、查看审核候选原值/标准值与队列折叠；没有提交任何浏览器科学审批。
- 隔离环境真实来源行克隆：含油率35.70%与另一独立样本的 FAME C14:0 0.25%；分组图表与文本表一致，证据能读到论文表页定位和原始文件摘要。
- 两条不同指标/计量基础记录的服务端比较正确提示身份、基础、方法和审核/许可不足，只能并列，未合成差异。
- 实验台把样本上下文交给助手，真实执行两次 getResearchSamples（57ms、21ms），回答保持 UNLINKED/SOURCE_REPORTED、没有生成式模型参与。

完整范围和限制见 [browser-report.json](../reports/ui-x/browser-report.json)。注册页面验证布局与交互提示；注册权限/CSRF/限流由 MySQL/REST 回归覆盖，未在生产创建账户或密码。不是完整 WCAG、多浏览器或公网验收。

## 性能与工程成本

使用同一 Python gzip 口径比较实际构建文件，详见 [performance-comparison.json](../reports/ui-x/performance-comparison.json)：

| 项目 | 改造前 | 改造后 |
|---|---:|---:|
| 首页入口 CSS 原始字节 | 67,408 | 51,537 |
| 首页入口 CSS gzip 字节 | 15,284 | 11,464 |
| 首页入口 JS 原始字节 | 75,102 | 78,760 |
| 首页入口 JS gzip 字节 | 29,215 | 31,132 |
| 全部路由 CSS 原始字节 | 80,599 | 100,308 |
| 全部路由 JS 原始字节 | 1,191,296 | 1,216,761 |

入口 CSS gzip 减少24.99%；页面与交互增加带来 JS 和全路由样式增长，未宣称整体包体积下降。三张真实图像共817,089字节，Hero约153KB，其他图像使用 lazy；浏览器可能按自身预取阈值提前读取。ECharts按需包仍约506.93KB / gzip171.66KB，并保留体积警告；Cytoscape仍按图谱路由加载，首页未同步引入两者。

没有改造前的可比浏览器时序基准或完整 Lighthouse 运行，不能从包大小推导首屏秒数/交互延迟收益。实际浏览器响应式与交互验收不等同于受控加载速度基准。
