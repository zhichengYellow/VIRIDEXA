## 工程交付

V3—V7 新迁移已通过应用 Flyway 实际执行，当前容器健康。源版本、候选、独立样本、观测、原文献链接、具名决定分别建模；外键、唯一约束与检查约束保持启用。正式发布要求最新具名决定批准、候选可规范化、直接来源及关联文献完整且许可允许。

run_science.py 支持 dry-run、文件哈希、ZIP 流式来源适配、审核过的缓存文件校验、批处理事务、失败报告与恢复重放。批量使用 JSON_TABLE INSERT SELECT，导入账号没有 UPDATE 权限或审核决定 INSERT 权限。业务 API 使用只读账号，Flyway 使用独立迁移账号。旧 Phase 1 导入脚本不应再使用已收窄的 Phase 2 凭证。

公开服务支持名称候选检索、形态条件、独立样本测量、种类/基础过滤、来源链、证据关系和发布覆盖统计。管理员只读数据检查要求现有 ADMIN 用户认证；没有为本轮创建用户。未来 Agent 直接复用 ScientificService；图谱与分析 DTO 已提供。部分植物专属属性仍以来源 JSON 承载，尚不等于完全统一的分类/性状本体。

命令与模型详见 PHASE2_ARCHITECTURE.md；真实示例见 reports/phase2/e2e-examples.json。
