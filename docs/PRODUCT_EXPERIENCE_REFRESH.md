# 新手引导与前端视觉更新

2026-10-26 · 当前本机应用：http://localhost:5173。

## 实现

新增五站新手指南：探索植物 → 植物详情 → 知识图谱 → 科研实验台 → Research Agent。首页首次访问显示轻量邀请卡，不强制弹窗；导航栏与首页首屏均可主动打开。

支持跳过、重开、步骤选择、继续引导浮条、刷新恢复进度与完成后隐藏提示。浏览器只保存本地引导进度，不复制植物知识数据。当前植物从URL提取后由公共API重新校验；不可访问时选择实际公开记录，无可用目录或网络故障时提供通用入口。引导不提交科学审核或调用模型。

使用原生dialog、语义化标题、步骤aria-current、显式Tab首尾循环、Escape退出、关闭后的焦点恢复与跳转后的主区域聚焦。手机使用紧凑步骤条；弹窗受视口高度约束，内容可滚动，背景滚动锁定。减少动画偏好继续生效。

视觉更新为森林绿、青柠、淡紫与奶油白；首页采用更清晰的无衬线标题、植物线稿贴纸、探索CTA、圆角目录卡和任务入口。重排全局胶囊导航，增加「探索」与「新手指南」。手机导航换成两行网格，管理审核入口保留在页脚。

共用设计变量与圆角/表单/状态提示规则覆盖助手、图谱、实验台、详情、登录页、技术看板；图谱深色画布保留。没有新增UI、图表或引导第三方依赖。

主要新增：`ResearchGuide.vue`、`GettingStartedCard.vue`、`stores/onboarding.ts`、`onboarding/progress.ts`、`experience.css`。修改首页、App导航、滚动定位与前端测试入口；Node测试仍由独立测试命令执行，不进入浏览器构建。
