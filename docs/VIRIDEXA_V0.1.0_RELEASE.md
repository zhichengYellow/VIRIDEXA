## 3. 媒体与前端收尾

28个有界目标查询中，17条精确物种目录获得21张合格照片；无合格结果继续无图。保留iNaturalist原始作者/署名字符串、观察URL、物种ID、许可、原图哈希和本地文件。CC0来源未提供具名作者时不虚构作者。来源research-grade是上游识别状态，不是本平台人工核验。

原图在`data/raw/images/`，WebP派生资源在`data/media/public/`，全部持久化且默认忽略Git。支持方向校正、响应式缩放、图片相册、加载失败回退、署名来源入口。没有配置R2/OSS，也没有实现对象存储适配器；本地演示不需要云凭据。

名称与媒体入口通过同一公开植物服务校验。媒体API最多12张，过滤物种不一致、非允许许可、异常文件名及非白名单来源URL。不返回服务器路径或坐标。图片是图鉴材料，不能充当新科学观测。

重复媒体导入前后，21条内容、身份、许可、公开状态与来源关系指纹相同：
`bcb1a078d4f273cf029987f1e2289da33be1c906bcec4b439b2f7f823c61b1c7`。

实际修改：首页、植物画廊、详情/相册、名称出处、图谱来源检查器、技术看板。复用现有图像、卡片、状态、研究上下文和布局；没有另建植物模型或审核流程。画廊首批优先展示有真实授权影像的目录。

本轮发现并修复：

- 手机首批加载时搜索按钮禁用会吞掉Enter提交：允许新条件中断旧请求，结果标题使用已提交条件，离开画廊取消请求。
- 新中文名的图谱节点与HAS_NAME连线必须使用自己的名录证据，不能继承植物原目录来源：现返回名称自己的文件哈希、版本与行定位，并有隔离MySQL回归。
- 文件级来源不能作为科研来源ID传入实验台筛选：仅为实际科研来源标识提供该跳转。
- MySQL容器UTC时区与JDBC原先Shanghai映射不一致：统一UTC连接映射，校验名称查询时间与数据库epoch相符，不修改原始证据字节。

- 科学内容、来源关系、候选状态、审核事件指纹不变。未关闭外键，不注入生产测试夹具。
- API只读账号、独立导入/迁移/账户/审核账号；CSRF、管理员越权、未登录Agent/实验台、发布撤回隔离、配额和异常路径测试通过。
- 本地隔离Nginx有界突发测试验证429、Retry-After、恢复、Host含端口保留、伪造IP头覆盖、静态资源不受API通用限流与请求体限制。没有攻击第三方或共享服务器。
- npm audit（含开发依赖）报告0项；OSV已查询93个Maven运行依赖，报告0项。容器基础镜像与可选Python依赖未完成等价漏洞扫描，不能称全部供应链无漏洞。
- 可达Git历史2个原有提交和最终发布源代码分别执行Gitleaks，未发现泄漏。历史无超过2MB的blob；发布暂存排除`data/`、`.env*`（模板除外）、动态原图、快照、日志和构建输出。只保留3张有来源的静态原件、小型WebP和真实截图。
- 应用公开派生图片目录是公开静态资产目录，禁止放私有图片；若撤下媒体，需同时移出公开目录并处理浏览器缓存。元数据状态不等于已下载文件可以收回。

## 7. 干净源代码复现

独立临时工作目录从待发布索引导出，不含科研`data/`、生产快照、真实`.env`或node_modules。实际执行npm ci、Vue生产构建和Maven package。生成本地随机环境配置并通过Compose解析。
