## 性能

构建前资产清单在 `reports/phase6/build-before.json`，最终清单在 `build-after.json`。可重复执行：

```sh
PATH=/Users/binyellow/.nvm/versions/node/v22.20.0/bin:$PATH npm --prefix apps/web run build
python3 scripts/frontend_bundle_report.py
```

| 指标 | 改造前 | 改造后 |
|---|---:|---:|
| 首页初始 JS（包含 modulepreload） | 123,799 B | 115,426 B |
| 首页初始 JS gzip | 47,082 B | 45,464 B |
| 实验台路由 JS | 512,513 B | 22,751 B |
| 实验台路由 gzip | 171,239 B | 8,096 B |

首页初始 JS 减少 **6.76%**。真实绘图仍需独立 ECharts 包 506,931 B（gzip 169,380 B），因此总绘图下载成本没有按路由包降幅减少。该包继续触发 >500KB 警告，没有提高阈值掩盖警告。Cytoscape 仍按图谱路由加载，约453KB；没有引入额外 UI 库。

`public-workbench-assets.json` 记录浏览器实际请求：公开空实验台没有请求 `charts-*`，也没有请求 Cytoscape。隔离真实来源样本图表成功按需绘制、显示单位和候选状态。异步绘图库加载后会复核请求序号、展示分组、模式与组件存活状态；图表容器被表格切换移除时也释放实例和观察器，重新显示时重新绑定；卸载仍释放图表、图谱、观察器和请求。现有页面在热更新构建后可能引用退休路由包，增加一次性重新读取当前 HTML 的恢复逻辑，避免无限重载。

`browser-metrics.json` 为当前单次浏览器指标。没有可比的改造前延迟基线，不宣称首屏延迟或帧率提升。构建耗时见最终 build.log，受本机负载影响，不作为速度收益。

## 浏览器验收

截图均在 `reports/phase6/`。生产端口5173与隔离端口5174分别验收，截图文件中 `isolated` / `catalog-fixture` 明确表示隔离技术夹具。

- 生产六页：首页、图谱、实验台、助手、审核登录、技术页，各375/768/1024/1440px，共24次尺寸检查；实际 innerWidth 与目标一致，整页无横向溢出。记录 `responsive.json`。
- 管理员审核表单、植物详情、真实候选图表另测四档宽度。最初375px许可表单滚动宽528px；修复后375px，记录 `responsive-remediation.json`。初始失败保留在 `isolated-responsive.json`，不掩盖初次问题。
- 生产：首页搜索“油菜”→真实空目录提示；问题携入助手；来源问题→真实领域服务→3步轨迹→来源卡→图谱来源/文件关系→来源筛选实验台。
- 隔离公开目录：`phase6_catalog_fixture.py` 仅向受保护前缀隔离数据库准备明确技术目录状态，支持首页搜索 Cycas→详情→图谱 plant:1→按植物筛选实验台→带plantId进入助手→公开目录记录与来源详情。没有发布任何科学测量，没有冒充人工科学审核。
- 隔离管理员：登录明确测试账户→候选原文/标准值/定位→内联核对→拒绝或退回补证→保存成功/版本反馈/历史；不是实际科研审核。
- 隔离样本：course-sample:1 刷新后恢复勾选，真实课程含油率10.65%仍标记 LEGACY_REVIEW_REQUIRED / CANDIDATE；证据入口正常；带候选上下文进入公共助手被服务端拒绝。
- 断开实验台API请求→故障提示→恢复请求并重试成功；不存在植物有明确错误与返回入口。
- 主要操作使用语义控件；跳转链接可按Enter激活，焦点到main-content；图谱保留文本节点/关系列表，图表保留同一数据表格；遵循减少动画偏好。没有完成外部读屏器或完整WCAG认证。

部分浏览器标签在开发重建过程中遇到旧分块加载失败；刷新当前HTML后完成上述路径。首次浏览器尺寸覆盖未作用到被测标签，已废弃该批判断，改用页面开发接口并逐项核对实际innerWidth后重新生成截图。浏览器临时尺寸和网络拦截已恢复。
