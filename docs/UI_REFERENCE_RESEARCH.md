## Application fit

The inspected app manifest is `apps/web/package.json`: Vue `3.5.44`, Tailwind CSS and `@tailwindcss/vite` `4.3.3`, Vite `8.3.5`, plus Pinia, Vue Router, Cytoscape, and ECharts. The Vue-first candidates (shadcn-vue and Inspira UI) align with the framework and Tailwind v4 generation; validate each copied component's current peer requirements and styling assumptions before integration. The React-oriented shadcn/ui is useful for principles and examples but not directly installable as Vue components. Vben is a larger admin starter/reference, while Dify and Langfuse are product-pattern references with license boundaries rather than drop-in UI kits.

For a botanical scientific product, prioritize high information clarity: stable navigation and page hierarchy; searchable, filterable tables; readable taxon/specimen cards; explicit source citations and provenance; confidence/status labels; graph controls that preserve context; and charts with units, time ranges, and legible legends. Use restrained botanical colors as semantic accents (for example, taxonomic status or evidence class), not as decoration replacing contrast. Favor reduced-motion behavior and accessible focus/keyboard patterns.

## Applied design decisions and browser access boundary

The implementation uses original Vue templates and SVG icons; no component source or whole page was copied from these projects. No new UI package was installed. Existing Vue 3.5 / Tailwind 4 primitives plus native dialog, details, controls and responsive CSS avoid importing an entire admin or AI product. This is deliberately a pattern study rather than a claim that a framework installation produces product design.

Applied: shadcn's composed shell / input / inspector hierarchy → AppShell, CommandSearch, PageHeader and StatusIndicator; Vue-specific native composition → BotanicalCard and quick preview; Vben's filter/queue/detail arrangement → dense candidate table and collapsible review queue; Dify's work area separation → question rail and result area; Langfuse's execution observability → actual ordered Tool Trace; Inspira's restrained bento rhythm → asymmetric landing and linked research tools. Branding, plant imagery, content, colors and page composition are original to VIRIDEXA.

Visual browser access was attempted for the official shadcn dashboard block (`https://ui.shadcn.com/blocks?category=dashboard`). Navigation created the page, but subsequent DOM inspection and screenshot calls repeatedly timed out (including a final bounded 10-second screenshot attempt). No usable reference screenshot was returned. Therefore this report **does not claim visual QA of the six external demos**. Official repository, documentation/component pages and licenses were read as noted above; local VIRIDEXA before/after pages, by contrast, were actually inspected and captured. No third-party login, CAPTCHA bypass or unpublished demo access was attempted. This access limitation remains part of the delivery.
