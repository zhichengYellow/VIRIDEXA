## 实现与重跑

V15—V22：来源授权账本、内容及来源摘要约束、公开来源投影、精确原文学名索引、目录授权及最新撤回规则、图谱统计快照。API 仍用只读账号；发布脚本使用临时最小授权身份，未关闭外键。

```sh
python3 scripts/pipeline/release_showcase.py --help
python3 scripts/pipeline/index_showcase_catalog.py --help
python3 scripts/pipeline/snapshot_showcase_graph.py --help
```

三者默认 dry-run，显式 `--apply` 执行。来源授权和目录索引支持分批事务。来源重跑新增授权为 0；目录两次重跑新增为 0，目录内容、名称与历史指纹一致。科学候选、样本、观测、来源关系和审核内容发布前后 SHA-256 指纹一致。统计快照只保存聚合数量，不复制科学行；实际重跑的内容指纹、节点数量和关系数量全部一致，未重复插入同一快照。

公开依据限于用户明确授权的课程展示以及事实型结构化记录。UNKNOWN 许可仍需进一步按具体上游资源核对；本轮没有公开论文全文、截图、长篇原文、图片或受限服务器路径，不表示取得了全文或媒体再分发许可。文件摘要验证证明版本对应，不代表内容科学核验。

## 产品与 API

- 首页：全部公开名称目录可检索、科属与名称条件、服务端分页与继续加载；不再以正式事实为 0 阻断目录。
- 植物详情：真实名称、来源形态、分开显示同名的不同来源记录、可信度与定位；不存在的中文名和属性不补造。
- 知识图谱：来源名称精确关系、性状词、样本与证据按需展开；SOURCE_PUBLIC 与 PUBLISHED 清楚区分。每页 1–40、一跳、游标绑定条件，端点重新检查权限。
- 实验台：登录后读取获准公开的来源测量；独立样本、原值、单位与基础保留；未关联与不可比给出原因。修复了样本列表可见但测量读取仍仅检查正式事实的问题。
- Agent：六个现有只读工具复用来源查询，标记来源陈述、机器提取、人工核验；真实模型未配置，实际为领域检索降级模式。
- 技术看板：系统分层、三管线、真实来源版本/摘要/许可、模块入口、安全边界与运行状态。统计请求与图谱独立加载，失败不阻断模块探索。

图谱本批次逻辑计数为 674,820 节点 / 771,666 关系，其中 392,781 为来源性状词出现节点；不是独立物种或已核验事实数量。数量为明确注明时间的发布批次快照；节点、关系和权限查询仍实时校验。大规模全库统计曾超时，已改为受控命令行聚合快照；候选等展开查询改用原生键过滤后再合并，避免全图物化。旧失败日志保留，不宣称从未发生失败。

## 自动化、浏览器与性能证据

最终运行结果与浏览器范围见 [测试摘要](../reports/showcase/test-summary.json)、[浏览器报告](../reports/showcase/browser-report.json) 及 `reports/showcase/screenshots/`。隔离数据由少量真实来源行克隆，全部标记技术夹具；未用于生产统计，也没有实际科学审批。

构建仍有 ECharts 按需包约 506.93 kB（gzip 171.66 kB）的提示；没有为了消除提示做危险拆包，也未声称本轮降低该包体积。图谱统计快照接口为亚秒级本地响应。修复前 Ginkgo 图谱搜索超时；复用目录服务后，一次实测 2.893 秒。NHM 来源一页 10 条关系从一次实测 16.907 秒降至 8.224 秒，仍是后续优化点；保留单条 SQL 5 秒超时，总展开事务有 20 秒截止。上述是本地单次对比，并非统计性能基准或公网保证，完整耗时见 `graph-live-before-final-optimization.json`、`graph-live-final.json` 和运行回归报告。

## 剩余边界

真实 LLM 联调为 0；没有 Key 或真实模型调用费用。具名科学审核为 0。18 个来源许可仍 UNKNOWN。7,068 样本身份未可靠关联，不能按植物名称自动挂接。公开目录主要是原文名称索引，中文名与图片覆盖有限。未部署公网、未做公网压力或 DDoS 测试。高级研究功能仍需公众账户登录；审核写操作仍需管理员与 CSRF。

本地 Docker 磁盘不足曾导致统计临时表失败；仅清理本项目可再生成的精确构建缓存。此前本项目 MySQL 旧 binlog 已完整归档至仓库外并核对 SHA-256 后轮转，未删除科研行、审核历史、其他项目或受保护资料。MySQL buffer pool 默认可配置为 512M；部署时应按服务器内存调整。
